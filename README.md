# LiveLoot

Free desktop app for TikTok LIVE: alerts, a lucky-wheel crate, Top Gift, follower goals and Actions & Events, shown in TikTok LIVE Studio as browser sources.

- Runs entirely on your PC. No account, no tracking, nothing sent to us.
- Windows installer and automatic updates come from this repository's Releases.

**Not affiliated with TikTok.** Prizes on the wheel are the streamer's responsibility. See `public/legal.html`.

## Build

```
npm install
npm run dist
```
